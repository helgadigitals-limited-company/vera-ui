## Features

- **Anchored positioning** — Aligns to trigger with configurable side and offset
- **Composable** — Header, title, and description helpers
- **Accessible** — Keyboard and screen reader support via Radix UI

### PopoverContent

<TypeTable
  type={{
    align: {
      type: '"start" | "center" | "end"',
      default: '"center"',
      description: "Alignment relative to the trigger.",
    },
    sideOffset: {
      type: "number",

      description: "Additional CSS classes.",
    },
  }}
