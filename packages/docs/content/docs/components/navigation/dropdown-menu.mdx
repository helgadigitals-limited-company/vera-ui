## Features

- **Rich menu items** — Labels, separators, shortcuts, and destructive variant
- **Checkbox and radio items** — Toggle and single-select options
- **Submenus** — Nested menus with `DropdownMenuSub`
- **Accessible** — Full keyboard navigation via Radix UI
