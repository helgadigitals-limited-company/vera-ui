## Features

- **Semantic markup** — Uses `nav` with `aria-label="breadcrumb"`
- **Flexible separators** — Default chevron or custom separator content
- **Ellipsis support** — Collapse long paths with `BreadcrumbEllipsis`
- **Composable** — Link, page, and separator subcomponents

## Components

| Component | Description |
|-----------|-------------|
| `Breadcrumb` | Root `nav` element |
| `BreadcrumbList` | Ordered list container |
| `BreadcrumbItem` | List item wrapper |
| `BreadcrumbLink` | Navigable link (supports `asChild`) |
| `BreadcrumbPage` | Current page (non-navigable) |
| `BreadcrumbSeparator` | Separator between items |
| `BreadcrumbEllipsis` | Collapsed segment indicator |
