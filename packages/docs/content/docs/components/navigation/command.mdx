## Features

- **Searchable list** — Filter items as the user types
- **Grouped items** — Organize commands with headings and separators
- **Dialog mode** — `CommandDialog` wraps the palette in a modal
- **Keyboard shortcuts** — Display shortcuts with `CommandShortcut`

## Components

| Component | Description |
|-----------|-------------|
| `Command` | Root container |
| `CommandInput` | Search input with icon |
| `CommandList` | Scrollable results list |
| `CommandEmpty` | Shown when no results match |
| `CommandGroup` | Grouped section with heading |
| `CommandItem` | Selectable command row |
| `CommandSeparator` | Visual divider between groups |
| `CommandShortcut` | Keyboard shortcut label |
| `CommandDialog` | Modal wrapper using Dialog |
